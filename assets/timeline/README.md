# Timeline photos

Add all montage frames directly into this folder using sequential names:

- `01.jpg`
- `02.jpg`
- `03.jpg`
- ...
- `70.jpg`

The reel reads consecutive files automatically and divides the full sequence into four visual timeline stages: 6, 7, 8 and 9 class. You do not need to sort photos into class folders.

Keep numbering without gaps. JPG files are recommended for quick loading; resize very large images before adding them.
