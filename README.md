# Личное цифровое письмо — версия 3

Интерактивный сайт ко дню рождения, 17 сентября 2026 года.

## Что внутри

Сайт состоит из 14 отдельных экранов, а не из длинной страницы. Между ними можно переходить кнопками, стрелками клавиатуры и свайпами на телефоне.

Добавлены:
- отдельная фотохроника 6 → 9 класс;
- 18 локальных слотов под фотографии;
- увеличение фотографии по нажатию;
- интерактивная временная линия;
- раскрывающиеся воспоминания;
- скрытая мысль, которая открывается по клику;
- Linux / IT-пасхалка;
- большое место под настоящее письмо;
- интерактивная секция «Спасибо»;
- финальное поздравление с конфетти;
- опциональный звук без автозапуска;
- адаптация для телефона, свайпы и ArrowLeft / ArrowRight.

## Фотографии

Все фотографии подключаются локально из `images/`.

Основные слоты фотохроники:
- `chronicle01.jpg` … `chronicle05.jpg` — 6 класс
- `chronicle06.jpg` … `chronicle10.jpg` — 7 класс
- `chronicle11.jpg` … `chronicle14.jpg` — 8 класс
- `chronicle15.jpg` … `chronicle18.jpg` — 9 класс

Также есть отдельные:
- `teacher1.jpg`, `teacher2.jpg`
- `together1.jpg`
- `class1.jpg`, `class2.jpg`
- `final.jpg`

Placeholder-файлы можно просто заменить фотографиями с теми же именами.

## Текст

Основной текст находится прямо в `index.html`.

Особенно много места подготовлено в:
- `editable-letter` — большое письмо;
- карточках `.memory-card` — конкретные воспоминания;
- подписи фотохроники;
- временной линии;
- финальном поздравлении.

## Запуск

Откройте `index.html` в браузере или запустите любой простой локальный сервер, например:

```bash
python -m http.server 8000
```

После этого откройте `http://localhost:8000`.

## GitHub Pages

1. Создайте репозиторий.
2. Загрузите содержимое этой папки.
3. В Settings → Pages выберите публикацию из ветки `main` и папки `/root`.
4. Через несколько минут сайт будет доступен по адресу GitHub Pages.
